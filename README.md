# Dice Rolling Game

## Project Information
- **Project title:** Dice Rolling Game
- **Programming language:** Python 3
- **Project number:** PS No. 47
- **School/department:** School of Computer Science and Engineering

## Description
This is a console-based dice rolling game. The user enters how many times a six-sided die should be rolled. The program generates a random result from 1 to 6 for each roll and displays the frequency of every face, the total, the average, and the most frequently occurring face or faces.

The program also checks that the number of rolls is a whole number between 1 and 1000 and gives the user the option to play again.

## Features
- Rolls a six-sided die using Python's `random` module.
- Accepts between 1 and 1000 rolls.
- Counts how often each face (1–6) appears.
- Calculates the sum and average of all rolls.
- Handles ties when finding the most frequent face.
- Validates invalid input.
- Allows the user to play again.
